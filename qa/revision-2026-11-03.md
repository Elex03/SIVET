# Revisión QA — SIVET — 3 de noviembre de 2026

## Correcciones

- Dashboard: Flujo por Categorías y Salidas por área ahora tienen área gráfica limitada (320 px, con margen para leyenda) y scroll interno. La fila de gráficas no se comprime dentro del contenedor flexible.
- Tablas: el render explícito de una columna tiene prioridad; las alertas críticas dejaban de mostrar su etiqueta y aparecían como «Sin estado».
- Reportes: refresh comunica éxito o fallo. Una recarga fallida ya no marca un reporte como recién generado ni le asigna una nueva hora de carga.
- Notificaciones: recordatorios y campana usan el mismo criterio de pertenencia a la cuenta. El perfil Consulta no muestra una campana que llevaba al inventario en lugar de una bandeja.
- Sesión: una operación iniciada en otra sesión no publica datos, mensajes de éxito ni nuevas escrituras después de un cambio de sesión. Las operaciones que ya llegaron al backend no se deshacen.
